# Редактировать текст без AI-штампов

Минимальная редактура с сохранением фактов и авторского голоса или поиск штампов без переписывания.

Авторский скилл `no-ai-slop`, опубликованный bushkarev-max под лицензией MIT.

[Полный текст скилла](skills/no-ai-slop/SKILL.md).

## Установка в Codex

1. Скачайте ZIP репозитория или клонируйте: `git clone https://github.com/bushkarev-max/no-ai-slop-auto.git`.
2. Прочитайте `skills/no-ai-slop/SKILL.md`. Проверьте существующие установки с тем же именем, включая прежние каталоги скиллов; не перезаписывайте локальные правила автоматически.
3. Скопируйте целиком папку `skills/no-ai-slop` в `.agents/skills/` своего проекта либо в `~/.agents/skills/` для всех проектов.
4. Начните новую сессию в нужном проекте и проверьте доступность скилла.

Каталоги и ручная установка описаны в [официальной документации OpenAI](https://developers.openai.com/api/reference/cli). Совместимость установщиков других ассистентов здесь не проверена.

## Пример

«Используй no-ai-slop: отредактируй этот черновик, сохрани факты и мою интонацию: …»

Для поиска штампов без редакторской правки попросите режим detect. Скилл не определяет AI-авторство текста и не предназначен для обхода детекторов.

## Проверки и ограничения

Это инструкции без встроенных программ, аккаунтов или платных API. Не устанавливаются автоматически ни программы, ни сам скилл.

Python 3, без внешних зависимостей:

```sh
python3 scripts/check_public.py
python3 -m unittest discover -s tests -v
```

Проверяются явный состав файлов, текстовый формат, символические ссылки, имена и описания скилла, типовые ключи/токены, email, локальные пути, IP-адреса и посторонние GitHub URL. Сканер не гарантирует обнаружение любой PII и не заменяет чтение каждого файла. Подробности — [SECURITY.md](SECURITY.md).

Проверки пакета и шесть тестов сканера пройдены локально. Проверки в GitHub Actions запускаются на push и pull request. Качество ответов модели на реальных заданиях этими проверками не подтверждается.
