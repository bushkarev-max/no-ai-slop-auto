# Безопасность публикации

Перед отправкой прочитайте каждый файл и вывод `git diff --cached --stat`. Запустите сканер и тесты. Проверьте автора и email коммита, дерево и отсутствие родителей первого коммита. Не добавляйте .env, cookies, ключи, журналы, видео, частные отчёты и дампы.

Сканер использует явный список файлов и разрешённых GitHub URL. Он отклоняет символические ссылки, нетекстовые файлы и ряд типовых признаков секретов, email, IP и локальных путей. Он не распознаёт любую PII, косвенное раскрытие клиентов, все форматы ключей или внутренние сведения по смыслу. Сетевой проверки прав доступа и юридической экспертизы он не выполняет. История Git проверяется отдельно перед первой публикацией; CI проверяет текущие файлы checkout.

Не помещайте настоящий секрет в публичную Issue. Если он уже опубликован, сначала отзовите/замените его у поставщика и сообщите владельцу через доступный приватный канал без повторной публикации значения. Удаление файла не удаляет его из истории и чужих копий.
