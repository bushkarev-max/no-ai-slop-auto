# Правила публичного репозитория

Прочитай .project-system.json, README.md и MASTER-SPEC.md. Этот репозиторий владеет только своими публичными пакетами. Не импортируй внутреннюю историю, личные настройки или данные пользователей.

Перед изменениями проверь origin, ветку/HEAD и локальные изменения. Сохраняй чужие изменения. Перед публикацией прочитай каждый включаемый файл, выполни `python3 scripts/check_public.py` и `python3 -m unittest discover -s tests -v`. Новые файлы требуют явного добавления в разрешённый состав сканера после проверки.

Не записывай секреты даже в примеры, тесты, commit metadata и отчёты. Используй публичный GitHub login и noreply-адрес для коммитов. Сообщения об уязвимостях не должны раскрывать секрет в публичной Issue. Закрытие задач и Done требуют приёмки владельцем; merge её не заменяет.
