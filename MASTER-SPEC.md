# Требования к Редактировать текст без AI-штампов

Репозиторий: bushkarev-max/no-ai-slop-auto. Собственные Issues хранят задачи; README — подтверждённые возможности и ограничения.

- Публиковать только проверенные переносимые пакет no-ai-slop-auto, их документацию и проверки.
- Сохранить функции редактора и проверки фактов, не обещать определение AI-авторства, просмотр недоступного видео или выполненные эксперименты.
- Лицензия MIT по решению владельца; сторонние материалы не включать без проверки прав и необходимых уведомлений.
- Начать с новой истории Git. Не включать внутренние URL, личные пути, конфигурации, данные клиентов, исходные видео и отчёты.
- Установка должна учитывать существующие навыки и не перезаписывать их автоматически.
- Сканер работает локально без сети и не печатает найденные значения секретов. CI запускает сканер и его тесты с минимальными правами.
- Новая публикация требует проверки всех изменённых файлов и фактического результата GitHub; успешные тесты не подтверждают качество ответов модели.
